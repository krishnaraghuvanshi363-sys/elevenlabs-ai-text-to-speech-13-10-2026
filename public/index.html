How This Application Works (Classroom Architecture)

1

Frontend Input

The user inputs text and selects a model. The browser validates that text is not empty.

2

Secure Server Bridge

The browser sends a request to /api/text-to-speech. The API key stays protected on the backend.

3

ElevenLabs API

The backend requests the ElevenLabs API using the server environment variable ELEVENLABS_API_KEY.

4

Browser Playback

Audio is returned as an MP3 audio stream, loaded into an HTML5 audio element, and played instantly.
